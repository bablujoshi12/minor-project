GALLERY IMAGES FOLDER
=====================

Yahan apni college ki photos upload karein.

File names example:
- campus_gate.jpg
- cultural_event.jpg
- aerial_campus.jpg
- sports_event.jpg
- etc.

Important:
1. Photos yahan (public/images) folder me upload karein
2. File names Home.js me gallery array ke saath match hone chahiye
3. Supported formats: .jpg, .jpeg, .png, .webp
