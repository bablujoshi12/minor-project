4. DATABASE SETUP & CONFIGURATION
================================================================================

DATABASE NAME: smart_campus

IMPORTANT TABLES:
- admins (Admin users)
- teachers (Teacher users)
- students (Student users)
- parents (Parent users)
- branches (Department/Branch information)
- notices (System notices)
- assignments (Student assignments)
- attendance (Attendance records)
- marks (Student marks)
- notes_board (Public notes/announcements)

SETUP STEPS:
1. Create Database:
   CREATE DATABASE smart_campus;

2. Import Schema:
   Run: database/complete_system_schema.sql

3. Insert Default Users:
   Run: database/insert_default_users.sql

4. Insert Sample Data:
   Run: database/insert_sample_attendance_marks.sql

BACKEND CONFIGURATION:
File: backend/config/database.js
- Host: localhost
- User: root (or your MySQL user)
- Password: (your MySQL password)
- Database: smart_campus

5. BACKEND SETUP & API ENDPOINTS
================================================================================

START SERVER:
cd backend
node server.js
OR
.\start-server.ps1 (Windows PowerShell)

PORT: 5000 (Default)

IMPORTANT API ENDPOINTS:

Authentication:
POST /api/auth/register - Register student
POST /api/auth/login - Login (Admin/Teacher/Student)
POST /api/auth/parent-login - Parent login

Admin:
GET /api/admin/teachers - Get all teachers
GET /api/admin/students - Get all students
GET /api/admin/parents - Get all parents
GET /api/admin/statistics - Get statistics
POST /api/admin/send-notice - Send notice
GET /api/admin/notices - Get all notices
DELETE /api/admin/user/:type/:id - Delete user
GET /api/admin/branches - Get all branches

Teacher:
GET /api/teacher/students - Get students (teacher's branch)
POST /api/teacher/send-notice - Send notice
GET /api/teacher/notices - Get sent notices
POST /api/teacher/attendance - Insert attendance
POST /api/teacher/marks - Insert marks
POST /api/teacher/assignments - Create assignment

Student:
GET /api/student/notices - Get notices
GET /api/student/assignments - Get assignments
GET /api/student/test-marks - Get test marks
GET /api/student/semester-results - Get semester results
GET /api/student/attendance-dashboard - Get attendance

Parent:
GET /api/parent/children - Get children list
GET /api/parent/notices - Get notices
GET /api/parent/child-attendance - Get child attendance
GET /api/parent/child-marks - Get child marks
GET /api/parent/child-assignments - Get child assignments

Public:
GET /api/students - Get all students (public)
GET /api/students/roll/:rollNo - Get student by roll number
GET /api/departments - Get all departments
GET /api/gallery - Get gallery images
GET /api/homepage/all - Get homepage data

Chatbot:
POST /api/chatbot/chat - Chat with AI

Notes Board:
GET /api/notes-board/public - Get public notes
GET /api/notes-board/all - Get all notes (admin)
POST /api/notes-board/create - Create note (admin)
PUT /api/notes-board/:id - Update note (admin)
DELETE /api/notes-board/:id - Delete note (admin)

8. INSTALLATION & SETUP INSTRUCTIONS
================================================================================

PREREQUISITES:
- Node.js (v14+)
- MySQL/MariaDB
- Git

STEP 1: CLONE & INSTALL DEPENDENCIES
cd ytproject
npm install
cd backend
npm install

STEP 2: DATABASE SETUP
1. Create database: smart_campus
2. Import schema: database/complete_system_schema.sql
3. Import default users: database/insert_default_users.sql
4. Import sample data: database/insert_sample_attendance_marks.sql

STEP 3: CONFIGURE BACKEND
1. Edit backend/config/database.js
2. Set MySQL credentials
3. Set database name: smart_campus

STEP 4: SET ENVIRONMENT VARIABLES
Create backend/.env:
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=your_password
DB_NAME=smart_campus
JWT_SECRET=your_jwt_secret
GEMINI_API_KEY=your_gemini_api_key

STEP 5: START SERVERS
Terminal 1 (Backend):
cd backend
node server.js

Terminal 2 (Frontend):
npm start

STEP 6: ACCESS WEBSITE
Open browser: http://localhost:3000

9. TROUBLESHOOTING GUIDE
================================================================================

ISSUE: Port 5000 already in use
SOLUTION: 
- Run: cd backend && .\stop-server.ps1
- Or: Kill process on port 5000 manually

ISSUE: Database connection error
SOLUTION:
- Check MySQL is running
- Verify credentials in backend/config/database.js
- Ensure database 'smart_campus' exists

ISSUE: Login not working
SOLUTION:
- Verify user exists in database
- Check JWT_SECRET in .env
- Clear browser cache & cookies
- Check backend console for errors

ISSUE: Student data not showing
SOLUTION:
- Verify students table has data
- Check branch_id mapping
- Ensure students have valid branch_id

ISSUE: Chatbot not responding
SOLUTION:
- Check GEMINI_API_KEY in backend/.env
- Verify backend server is running
- Check network tab for API errors
- Try refreshing page

ISSUE: Images not loading
SOLUTION:
- Check public/images folder exists
- Verify image paths in database
- Check backend static file serving

ISSUE: Attendance/Marks not showing
SOLUTION:
- Run: database/insert_sample_attendance_marks.sql
- Verify attendance & marks tables exist
- Check student_id matches in tables
